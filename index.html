Sobre o Fiscalizaí

O Fiscalizaí é um PWA (Progressive Web App) que facilita o acompanhamento de emendas parlamentares do orçamento federal brasileiro.

Os dados são obtidos diretamente do Portal da Transparência do Governo Federal via API pública, sem nenhum intermediário.

Funcionalidades:
• Busca por parlamentar, período e função
• Filtros rápidos por situação de pagamento
• Armazenamento local das emendas de interesse
• Exportação em CSV
• Funciona offline com dados salvos

Fonte: portaldatransparencia.gov.br
v1.0 — Dados públicos do Portal da Transparência
